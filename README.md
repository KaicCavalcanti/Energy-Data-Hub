# Energy Data Hub

Projeto de portfólio desenvolvido para aprender Python,
integração com APIs, banco de dados e desenvolvimento backend.

## Objetivo

Buscar dados públicos do setor elétrico brasileiro, tratá-los,
armazená-los em PostgreSQL e disponibilizá-los por uma API própria
e uma interface de visualização.

## Tecnologias planejadas

- Python e Requests para coleta de dados.
- Pandas para tratamento e análise.
- PostgreSQL e SQL para armazenamento e consultas.
- FastAPI para construir nossa API.
- Streamlit para a interface.
- Git e GitHub para versionamento.

## Status

Projeto em etapa inicial de preparação.
A fonte de dados ainda será selecionada e validada.
